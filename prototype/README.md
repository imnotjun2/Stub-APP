# Stub｜生活存根 HTML Demo

这是一个按“奶油票根”视觉方向制作的移动端网页 Demo。它不是原生 iOS App，但可以在手机浏览器里使用，并保留 iPhone / Pixel 10 的预览外壳，方便继续讨论和验证产品体验。

## 当前可用能力

- 拍摄票据或从相册选择真实图片。
- 在浏览器内压缩并预览图片，不上传到服务器。
- 编辑标题、日期、类型和一句话记忆。
- 保存到本地时间轴，刷新后仍然保留。
- 查看存根详情、删除自己的记录、按类型筛选。
- 在 iPhone 与 Pixel 10 预览尺寸中检查布局。

## 当前边界

数据只保存在当前浏览器的本地存储中。清除浏览器网站数据后，自行添加的存根也会被清除。首版没有账号、云同步、自动裁边或 OCR；这些能力将在产品闭环验证后再决定是否投入。

## 本地启动

准备好 Node.js 后，在这个目录中运行：

```bash
pnpm install
pnpm dev
```

随后打开终端显示的本地地址。开发阶段建议先使用手机浏览器测试“拍摄票据”，桌面浏览器测试“从相册选择”。

## 主要文件

- `src/Prototype.tsx`：页面、上传、保存、筛选与详情逻辑。
- `src/prototype.css`：Stub 配色、字体、布局和交互状态。
- `public/reference-crops/`：选定视觉稿中提取的示例票根素材。
- `design-qa.md`：与选定视觉稿的对照检查记录。
