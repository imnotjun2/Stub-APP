# 生活存根 Stub 微信小程序 Demo

这是 `Stub｜生活存根` 的原生微信小程序版本，不是网页套壳。第一版用于零服务器成本验证核心体验：选择或拍摄真实票据、手动补充信息、保存到当前设备，并从首页、旅册和存根墙查看同一条记录。

## 已实现

- 奶油纸张视觉和 `Stub / 生活存根` 品牌层级。
- 从相册选择或直接拍摄真实票据。
- 电影、旅行、展览、餐饮、购物和其他分类。
- 电影格式、影院、影厅、座位以及机票/火车票路线字段。
- 标签、日期、地点、记忆文字和旅册归类。
- 首页、旅册、旅册详情、存根墙、详情、编辑和“我的”页面。
- 票据图片写入小程序 `USER_DATA_PATH`，元数据写入本地 Storage。
- 一条 `StubRecord` 只存一份；旅册使用 placement 引用，不复制记录。
- 本地记录编辑、删除和恢复初始示例。

## 如何打开

1. 从微信官方下载安装“微信开发者工具”。
2. 选择“导入项目”。
3. 项目目录选择：`/Users/bytedance/Documents/Stub/miniprogram`。
4. 当前工程已绑定注册的小程序 AppID；若复制给其他开发者，应改为对方有权限的 AppID 或测试号。
5. 导入后点击“编译”，首页会显示三枚示例存根。

当前帐号名称为“生活存根Stub”，简称为“生活存根”。真机预览、提交审核或添加体验成员都需要使用具备该 AppID 权限的微信帐号。

## 本地数据说明

当前版本完全不接服务器。真实票据会被复制到小程序本地用户目录，其他字段保存在 `stub.archive.v1`。删除微信、清理小程序数据或更换手机后，数据可能丢失；因此该实现只适合 Demo，不应被宣传为备份产品。

正式版本建议增加：用户确认后的加密云备份、数据导出、隐私保护指引、账号注销和服务端访问控制。票据可能包含姓名、订单号、二维码、座位和行程信息，云端版本不能使用公开读权限。

## 本地检查

工程没有 npm 依赖。安装 Node.js 后运行：

```bash
cd /Users/bytedance/Documents/Stub/miniprogram
npm run check
npm test
```

`npm run check` 会检查页面注册、JSON、WXML 标签、脚本语法、跳转路由和示例素材；`npm test` 会验证本地 Archive、旅册引用、图片持久化和删除契约。

开发者工具 QA 截图保存在项目目录外的 `/Users/bytedance/Documents/Stub/qa/miniprogram`，避免截图文件变化触发小程序热重载。
